What this is

Double-Booking Radar is a TokenMax burn-pool build: a local, offline calendar conflict detector. It surfaces hard overlaps, travel-time squeezes between sites, and ticket/event clashes — then offers a Pick one card per conflict.

  • Week timeline with conflict highlighting
  • Travel matrix: Millersville (home) ↔ Pasadena (office) / Annapolis / fields
  • Resolution cards that keep one event and drop the other (local only)
  • Hash routes: #week · #conflicts · #about

DEMO data

This build uses a clearly labeled EXAMPLE / DEMO synthetic calendar. Fictional conference sessions, kids sports practices, and generic work meetings — no KPD client matter names, no real Outlook sync.

Outlook Calendar connector still needs Microsoft org admin approval. Until then, remaining on demo keeps private dockets out of the box.

source: EXAMPLE tz: America/New_York port: 4306

How conflicts work

  1. Overlap — two events share the same person and time range.
  2. Travel squeeze — gap between back-to-back events at different places is shorter than drive time + buffer.
  3. Ticket clash — a ticket/event block overlaps another commitment for the same attendee.

Picks are stored in localStorage for this browser only and never leave the machine.
